# 证据驱动设计

企业站、B2B、专业服务或其他依赖可信证明的模块使用。本文件是内部 QA，不创建独立 Asset Check 报告。

## 设计前检查

选择 Layout 前自行确认：

- 模块要证明什么；
- 哪些真实素材和数据可用；
- 缺少什么，上线前是否必须补齐；
- 主视觉应使用产品、场所、人物、过程、数据还是文件；
- 是否允许文字为主，以及占位素材的真实性边界。

制造业常见证据包括产品、设备、工人、工艺、检测、证书、包装、库存和发货。其他行业选择与采购决策真正相关的人员、过程、结果、数据或文件。

关键素材缺失时只向用户报告缺口和影响。不得用图标、通用图库或文字卡片伪装真实企业证据，也不得把生成图当成真实事实。

## 表达检查

- 主视觉必须参与信息表达，而非纯装饰；
- Card 只用于真实分组、选择或独立对象；
- 不因缺少 Layout 想法默认使用 Card Grid；
- CTA 靠近能够支持行动的证据；
- 重要证据的视觉重量与决策价值相匹配；
- 移动端不能退化为过长的同质卡片列表。

检查结果默认不展示；只有缺口会阻塞设计或上线时才向用户说明。
