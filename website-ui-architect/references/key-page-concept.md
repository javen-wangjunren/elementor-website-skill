# 加强评审页面概念与整页主线

是否需要加强评审，不由“首页/内页”名称决定，而由影响和风险决定。会成为全站样板、承担主要转化或信任、高流量入口、采用新概念或重大改版、包含复杂媒体交互、设计不确定性高的页面，应建立页面概念和整页主线。其他设计页面仍要完成标准评审，但不强制制造独立概念或 Signature；小调整和精准还原任务跳过。

## 1. 盘点企业专属输入

从已确认的 Page Content、Design System 和真实素材中列出 4–8 个只属于当前企业或当前业务的具体事物，例如：产品几何、加工过程、测量记录、报价文件、样件变化、设备动作、场所、数据结构或交付节点。

每项必须能追溯到事实。不能为了设计概念编造工厂、设备、客户、数字、文件或流程。

## 2. 把页面主张变成具体画面

用一句话回答：访客第一眼看见什么具体对象，以及它如何表达本页最重要的业务主张。句子必须包含真实对象和关系，不能只写“专业、科技、可靠、国际化”。

示例结构：

```text
让 <具体对象/过程> 成为主视觉，通过 <可见变化或关系> 说明 <业务主张>。
```

## 3. 同行替换检验

把企业名称、Logo 和品牌色换成一个同行：

- 如果概念仍完全成立，说明它只是行业通用表达，需要补入当前企业的真实特征；
- 如果只能靠装饰区分，说明概念不足，不应继续增加特效；
- 如果内容与对象确实只在当前企业成立，记录其证据来源和可迁移边界。

目标不是追求奇怪，而是减少“换个 Logo 也一样”的模板感。

## 4. 选择首屏骨架

首屏不默认左文右图。根据内容和媒体任务选择，例如：

- 单一真实对象居中或占据主要画面；
- 全宽证据媒体与紧凑主张叠置或相邻；
- 以流程、数据、文件或界面关系作为主要画面；
- 大型排版与少量真实对象形成主次；
- 拼贴、叠层或方向性构图表达多个证据的关系；
- 左右分栏：只有文字与媒体确实需要并列理解时使用，并写明理由。

选择记录为 `Hero Structure`，同时说明在代表性桌面宽高和手机上如何保留主张、对象和主要动作。

## 5. 延续到首屏以下

从首屏概念提取一个可复用但不重复的视觉主线，例如几何、路径、尺度、材料、编号方式、媒体关系或信息揭示方式。它应在 2–4 个关键节点产生变化，不要求所有 Section 外观相同。

检查：

- 首屏的核心对象、形状或叙事是否在后续证据中得到解释；
- 后续是否全部退回相同三列卡片；
- 强弱、密度、Surface 和媒体重量是否形成松紧节奏；
- Signature Visual Device 是否只在最有价值的位置出现；
- 普通说明模块是否可以保持简单，不为维持“概念”而过度设计。

## 输出字段

写入页面 Architecture Map：

```text
Page Visual Throughline:
Distinctive Concept:
Hero Structure:
Signature Visual Device:
Whole-page Continuity:
```

`Signature Visual Device` 可以是静态装置，也可以是经确认的 Motion Signature；默认允许为 `None`。页面概念已确认不等于实现已通过，最终仍由 HTML 和加强视觉评审验证。
