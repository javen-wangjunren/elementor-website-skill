# Simple Reference-led Widget Fast Path

用于既有 Elementor 页面只新增一个简单独立模块，且用户希望从明确截图、Figma、图片或现有 DOM 直接实现 Widget。它是受控的实现捷径，不是简化版 UI 设计流程。

## 必须同时满足

- 目标是既有 Elementor 页面中的一个新增或迁移模块，不是完整页面设计。
- 用户明确要求或确认从当前强参考直接实现，不需要先生成独立 HTML。
- 标题、正文、CTA、图片等真实内容及必要链接明确。
- 参考能明确判断结构、层级、视觉重点和基本响应式降级；页面容器、字体、颜色或相邻背景可从现有页面或用户说明获得。
- 模块信息结构简单，只有一个合理实现方向；不包含复杂 Gallery、流程证据、数据关系、媒体浏览策略或显著交互设计。
- 目标插件和当前 Widget 边界可确认；插件不存在时仍先转 `elementor-site-initialize`。

常见适用：单一 CTA Banner、提示条、简短标题 + 正文 + 按钮、简单 Logo Strip、无交互的单图宣传块。

## 任一出现即退出

- 用户问“应该怎么设计”、要求多个方向，或参考只表达气质而没有明确结构。
- 需要重新决定信息主次、证据归属、图片比例、Gallery/Carousel/Viewer、移动端叙事或前后 Section 关系。
- 多状态 Tabs、复杂 Accordion、筛选、表单流程、业务计算或其他需要先验证体验的交互。
- 内容、素材真实性、页面宽度或关键视觉规则不足，直接实现会产生明显猜测。

退出动作：设计问题转 `website-ui-architect`；设计已确认但需要可审核 HTML 时转 `website-html-prototyper`。只返回缺失环节，不强迫整页流程。

## 参考解释与确认

在最小字段卡中增加：

```text
SOURCE MODE: strong-reference-fast-path
REFERENCE SOURCE:
REFERENCE INTERPRETATION:
- 保留的结构与视觉重点
- 需要适配现有页面的部分
- 桌面到移动端的最小降级
NOT RECREATED:
```

- 只解释影响实现的决定，不创建独立设计文档或 HTML。
- 不复制参考中的外部品牌标识、受版权保护素材、虚构证据或无关内容。
- 缺少既有 Slug 时，按模块业务任务提出一个稳定的 kebab-case Slug，随字段卡一次确认；不得使用 `new`、`final`、`v2` 或纯数字。
- 用户确认字段卡即同时确认参考解释、Slug 和固定实现边界，之后才能创建 PHP/CSS/可选 JS。

## 验证重点

- 与确认的参考解释比较结构、层级、视觉重点和响应式降级，不声称像素级复制。
- 同时放入现有页面上下文检查容器、背景、字体继承和相邻间距。
- 若真实实现暴露出需要重新设计的问题，停止修补并退出快速通道。
