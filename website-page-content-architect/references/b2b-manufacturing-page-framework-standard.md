# B2B Manufacturing Page Framework Standard

仅在 B2B 制造业网站的服务页、产品页、行业方案页、首页或企业信任页规划中读取。它由用户提供的《企业 B2B 制造官网｜页面内容框架规划标准化 SOP 技能手册》整理而来，是专项决策参考，不是所有网站的固定模板。

## 1. 常见决策角色与问题

- **采购**：供应范围、交期、稳定性、沟通与商业风险。
- **工程师**：材料、工艺、参数、公差、DFM、可制造性和技术边界。
- **质量角色**：检测流程、标准、认证、追溯和一致性。
- **管理或项目负责人**：供应链复杂度、总体风险、规模能力和项目结果。

页面需要识别主要角色。不要为了覆盖所有角色而把全部技术百科和公司资料堆进一个页面。

## 2. 推荐决策链

常见 B2B 制造访客会依次确认：

```text
业务是否匹配
→ 能否解决我的具体制造问题
→ 能力范围和限制是否合适
→ 是否有真实证据可以信任
→ 合作、交期、质量或知识产权风险如何控制
→ 下一步如何询价、传图或沟通
```

这是规划起点，不是不可调整的固定顺序。高风险或陌生品牌页面可以提前放一条强证据；已具备明确采购意图的页面可以更早展示能力边界和询价入口。

## 3. 内容层级

- **定位层**：首屏说明服务、适用客户、核心结果和主要行动。
- **预览层**：展示完成匹配判断所需的高频材料、工艺、行业、零件或案例子集。
- **详情层**：完整参数、材料库、表面处理库、案例库或技术指南进入明确详情页。

预览数量由内容和页面节奏决定，不固定为某个数字。每个预览模块必须说明它链接到哪里，以及当前页不负责展开什么。

## 4. 价值、能力与证据

- 先让访客判断“是否适合我”，再展开企业实力；但强信任信号可在首屏附近轻量出现。
- 技术能力必须同时说明范围与限制，避免只有宽泛的“全工艺、全覆盖”。
- 案例、评价、数据、认证、设备和工厂素材各自回答不同信任问题，不要合并成无层级的徽标墙。
- 相同卖点可以在 Hero 中摘要、在后文用证据展开，但不能原句重复。
- Why Choose Us 只有在它汇总的是可证明差异时才成立；不能成为剩余宣传内容的收纳箱。

## 5. CTA 策略

- Primary CTA 通常为询价、上传图纸、提交项目需求或预约工程沟通，必须对应真实流程。
- Transitional CTA 可以是查看能力、案例、指南或下载资料，只在降低当前决策摩擦时使用。
- 页面末尾通常需要明确收口，但不强制所有中间模块都放按钮。
- CTA 文案不得承诺未经确认的响应时间、报价速度或工程师匹配能力。

## 6. 常见页面模型

以下是候选骨架，使用前必须结合页面目标、流量意图和证据调整。

### 服务页

```text
服务定位与行动
→ 适用需求 / 能力预览
→ 技术边界与可制造性
→ 案例或质量证据
→ 合作流程与风险处理
→ 异议处理（需要时）
→ 转化收口
```

材料、表面处理、行业和案例不必全部独立成模块；信息量少或任务相近时可以合并。

### 产品页

```text
产品价值与适用场景
→ 关键规格和选择依据
→ 工艺 / 品质 / 兼容信息
→ 使用或行业证据
→ 采购顾虑
→ 转化收口
```

### 行业方案页

```text
行业问题与结果
→ 方案机制
→ 适用工艺和能力边界
→ 行业证据
→ 风险与合作方式
→ 转化收口
```

### 首页

```text
企业定位
→ 主要服务路径
→ 差异化价值
→ 代表性证据
→ 行业 / 案例入口
→ 信任与转化
```

### About / Capability

根据页面任务选择品牌定位、发展事实、团队、设备、质量、认证或合作方式。不要把所有公司资料视为必选项。

## 7. 模块合并与去重

重点检查：

- 优势、保障、质量、工厂实力是否重复表达“我们可靠”。
- 技术参数与 DFM 是否需要同一决策上下文，还是应拆成摘要与详情。
- 服务矩阵是否与流程、能力列表重复。
- 行业和应用是否只是换词后的同一分类。
- 案例模块是否拥有真实案例，而不是空壳或泛化场景。
- FAQ 是否确实解决阻碍转化的高频问题；没有真实问题时可以不设。

同质内容优先合并，但不要为了“只出现一次”而把不同决策阶段需要的摘要和证明错误地挤在一起。

## 8. 素材可行性

每个模块都要标记可用素材：

- 实拍零件、设备、工厂或团队；
- 参数表、工艺边界、流程资料；
- 真实项目案例和可公开结果；
- 检测数据、证书、质量体系；
- 客户评价、Logo 和授权范围；
- 聚合页或详情页链接。

默认项目方可以后续准备产品、认证、设备、工厂、检测、团队和应用素材。缺少当前素材时先判断模块是否对页面任务有价值：必要模块保留并列出内容要求；Case Study、Testimonials、客户 Logo 或数据证明可标为 `Recommended` 供用户决定是否在当前阶段启用。

素材可后补不代表事实可以预写。案例对象、评价原文、客户身份、认证状态、设备参数和量化结果必须在真实资料到位后才能成为访客可见主张。

## 9. B2B 页面结构自查重点

- 顺序是否符合采购、工程和质量角色从业务匹配到风险判断再到行动的过程？
- 产品/服务入口、能力范围、实体制造证据、质量追溯和 CTA 是否共同完成页面任务？
- 是否因素材尚未整理而漏掉关键产品、设备、认证、应用或信任模块？
- 是否连续使用多个模块重复“可靠、专业、工厂实力强”？
- Heading 是否直接说明材料、工艺、能力或客户结果，避免抽象企业口号？
- 技术信息是否被压缩为可扫读的分类、数据或列表，而不是文章式段落？

## 10. Page Family 专项规则

同类 CNC、3D 打印、注塑或行业页面可以共享基础 Section Job，但每页必须明确：

- 独有客户问题和搜索意图；
- 具体材料、工艺或应用边界；
- 独有案例、参数或证据；
- 与聚合页和其他服务页的 Preview / Detail 关系；
- 哪些模块仅替换数据，哪些模块必须重新规划内容。

禁止只替换服务名、行业名和 SEO 关键词后批量复制页面。

## 11. 移交边界

本阶段确定内容、模块、顺序、证据、边界、CTA，并在事实充分时提供可直接排版的 UI-ready 参考文案。最终营销精修、视觉风格、背景节奏、布局 Form、交互、SEO 配置和工程实现交给后续对应流程。
