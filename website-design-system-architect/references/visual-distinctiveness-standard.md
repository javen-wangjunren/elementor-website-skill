# 视觉辨识度与预算

用于回答两个问题：这套视觉为什么属于当前企业，以及为了保持主次，一页能使用多少种强视觉手段。本文件只约束跨页面的基础系统，不决定具体页面布局。

## Visual Identity Driver

每套新建或重建设计系统至少记录 2–4 个视觉身份驱动因素。它们必须来自已确认的品牌、产品、工艺、材料、场所、客户任务或内容证据，例如：

- 产品几何、加工轨迹、材料表面或测量方式；
- 企业真实的文件、设备、样件、场景和交付过程；
- 已确认的品牌历史、颜色来源、语言气质或受众决策习惯。

每个因素写清：`来源 / 可影响的视觉角色 / 不能被滥用的边界`。不能只写“专业、现代、高级”，也不能为了制造个性编造企业特征。

颜色、字体、形状和材质选择需要能回到这些因素。若把公司名称和 Logo 换成同行仍完全成立，说明辨识度不足；此时保持为 `Open`，等待真实页面验证，不靠增加装饰解决。

## Visual Budget

视觉预算用于限制一页同时争抢注意力的手段。默认建议不是硬性数字，品牌证据或真实页面可以覆盖，但覆盖必须说明原因。

- 字体家族通常不超过 2 个；常用字重维持有限组合；
- 强调色只服务主操作、当前状态和少量业务信号；
- Radius、Shadow、Border、Surface 各自形成有限尺度族，不为每个组件重新发明；
- 同一屏通常只有一个最高注意力对象；关键页面整页通常只保留一个主要 Signature Visual Device；
- 图标底板、渐变、发光、标签、装饰线等都计入视觉预算，不能因为单个元素很小就无限叠加；
- Hover、Focus、Active、Disabled 和语义状态属于必要状态，不因视觉预算被省略。

## B2B 反默认模板检查

以下现象不等于一定错误，但必须有品牌、内容或交互理由：

- 无理由的渐变、发光、玻璃效果和大面积高饱和背景；
- 几乎所有内容都被装进相同圆角卡片；
- 通用线性图标统一放进装饰方块，却没有信息作用；
- 颜色、圆角、阴影和材质无法说明与企业的关系；
- 每个模块都使用相同的眉标、标题、描述和三列卡片；
- 只做默认状态，缺少键盘 Focus、Disabled 或语义反馈；
- 为了“显得高级”扩大留白、压低对比度，反而降低信息效率。

检查方法：先删除无目的装饰，再判断信息层级是否仍成立；若删除后更清楚，就不应恢复。已有品牌系统或可访问性要求优先，不为追求“反模板”而破坏熟悉性和可用性。

## 真实页面验证

Design Board 只验证系统组合，不对辨识度打分。最终以一个代表性真实页面判断：

- 身份驱动因素是否能被真实内容支撑；
- 视觉预算能否保持主次和节奏；
- 媒体、组件和长短不一的真实文案是否仍适配；
- 默认模板现象是否在整页重新出现。

问题只出现在单页时交给 UI Architect；多个页面重复出现且根因属于共享规则时，才更新 Design System。
