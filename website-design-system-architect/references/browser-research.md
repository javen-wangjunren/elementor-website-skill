# 浏览器证据协议

New Site 深度研究确认后的同行网站时使用；Existing Site 提取现站视觉证据时也使用。目标是观察真实渲染结果并抽查关键实现规则，不做全站爬取、完整竞品报告或前端逆向工程。

## 1. 工具优先级

候选发现使用网页搜索和内容读取。视觉研究按以下顺序选择：

1. 当前环境存在 `ego-browser` 时优先使用；先完整读取其 `SKILL.md`，遵守 Task Space、截图、交互验证、控制权与清理规则。
2. 其他能够真实渲染页面、截图、交互并检查 DOM/CSS 的浏览器工具。
3. 用户提供的桌面与移动截图；明确截图未覆盖的交互和响应式未知项。
4. 只有内容抓取时仅记录业务和文字事实，不据此宣布视觉规则，并披露视觉结论可信度不足。

网站受登录、地区、反爬或付费限制时，请用户提供可用截图或接管浏览器完成必要访问。不要绕过限制，也不要用搜索摘要伪造页面观察。

## 2. 研究范围

每个网站默认查看：

- Home；
- 一个核心产品或服务页面；
- 与当前目标直接相关时，再查看 About 或 Quality。

每站默认保存 2–4 张关键截图，覆盖桌面首屏、主要内容模块和一个移动视图。证据保存到：

```text
设计稿/research/<research-id>/
```

使用可识别的文件名，包含网站、页面和视图，例如 `example-home-desktop.png`。截图只用于内部研究，不作为最终网站资产。

## 3. 观察与抽查

视觉观察集中在：

- 第一视觉焦点；
- 图片、视频与文字的比例；
- 页面密度与留白；
- 主要构图方式和卡片使用程度；
- 产品、人员、过程、结果、资质等证据如何出现；
- CTA 与证据的相对位置；
- 桌面与移动端的主要变化；
- 与任务有关的导航、hover、focus 或展开状态。

DOM/CSS 只抽查主色、字体、内容最大宽度、主要间距、圆角、常用图片比例、关键断点和一个典型交互状态。记录实际观察与推断的区别。

禁止：

- 仅凭 HTML 或文本抓取宣布完整视觉规则；
- 无目标地浏览整个网站；
- 完整复制同行 CSS、Tokens、组件或品牌语言；
- 把重复出现的模式自动判断为适合本项目；
- 因页面不可访问而补写不存在的视觉细节。

## 4. 收口

研究结束时保留 URL、查看日期、必要截图和与当前设计决定有关的少量观察。使用 Ego Browser 时，研究完成后按其 Skill 规则关闭 Task Space；只有需要用户在同一页面继续操作时才保留。
