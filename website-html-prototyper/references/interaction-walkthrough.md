# 开放式交互走查

只用于加强评审范围中包含主要 Tabs、Viewer、Carousel、Accordion、Lightbox、复杂菜单或其他高价值状态交互的页面或模块。静态 CTA、普通链接和基础 Hover 不触发。

## 给走查者的输入

使用未参与实现的评审者，只提供：

- 页面入口；
- 一个主要桌面视口和按需的手机视口；
- 可测试的内容/账号边界；
- 禁止提交、购买、删除、公开发布或修改真实数据等安全边界。

不要告诉评审者预期点击路径、控件应如何工作、源码位置、设计理由或已知问题。让其自然判断从哪里开始、如何切换、如何返回和下一步在哪里。

## 观察内容

- 入口是否可发现，当前状态是否清楚；
- 操作与目标内容是否靠近，切换后媒体、文字、图注、价格和链接是否同步；
- 再次选择、边界、关闭、键盘、Touch 和手机状态是否自然；
- 快速重复和动画中反向操作是否留下错误中间状态；
- 控件是否把用户带离内容、要求滚到下一屏才能继续，或用 Hover 隐藏关键信息；
- Reduced Motion 和 JavaScript 失效后是否仍可理解和操作。

这不是可用性研究，不计算用户成功率，也不替代真实用户测试。输出只记录可复现的行为问题，不给审美分数。

## 主 Agent 复现

主 Agent 必须复现走查者报告的问题，记录具体入口、操作、视口和结果。无法复现时保留为观察项，不直接修改。确认后按根因路由 UI Architect、Prototyper 或 Widget Pipeline；修复后只重测原问题和直接受影响路径。
